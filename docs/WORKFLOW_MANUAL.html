3. Complete Step-by-Step Execution Workflow

STEP 1
Prerequisites Check

Ensure Node.js 20 or higher is installed on your laptop:

node -v    # Must be v20.x or v22.x
npm -v     # Must be v10.x or higher
STEP 2
Workspace Folder Setup

Create a directory on your machine and open it in VS Code:

mkdir ieee-80211-wlan-lab
cd ieee-80211-wlan-lab
code .
STEP 3
Environment File Configuration (.env)

Create a .env file in your project root directory:

PORT=3000
# Optional: Provide Gemini API Key for online reasoning (fallback engine runs locally if omitted)
GEMINI_API_KEY="YOUR_GEMINI_API_KEY_HERE"
STEP 4
Install All Dependencies

Run the package manager inside the project root terminal:

npm install
STEP 5
Launch Development Server

Start the full-stack server running Express and Vite together on port 3000:

npm run dev

The console will display: Server listening on port 3000.

STEP 6
Open in Web Browser

Open Google Chrome, Brave, or Firefox and navigate to:

http://localhost:3000
STEP 7
Validate Type Safety & Build for Production

Run TypeScript compilation check and production bundle:

npm run lint    # Runs tsc --noEmit (must pass with 0 errors)
npm run build   # Compiles frontend assets into dist/
npm start       # Starts production Node.js server

4. AI Collision Prediction & Normalcy Controller Mechanics

The application includes an autonomous multi-layer contention governor designed to detect and reverse contention collapse:

Mitigation Mechanism Protocol Implementation & Collision Recovery Effect
RTS/CTS Virtual Carrier Sense Replaces 1500-byte packet collisions with 20-byte control frames. Prevents overlapping transmissions between hidden stations separated by >35m. Reduces collisions by up to 82%.
Wi-Fi 6 OFDMA Scheduling Partitions 20MHz/40MHz channels into 26-tone parallel Resource Units (RUs). Trigger frames schedule up to 9 stations in parallel, completely bypassing CSMA/CA random backoff contention. Reduces collisions by 92%.
Idle Sense / Q-Learning CW Dynamically scales contention windows based on observed channel idle slots rather than legacy binary exponential doubling (BEB). Prevents cyclic reset to CWmin that triggers contention spikes.
CoDel Active Queue Management Enforces a 5ms sojourn delay threshold. Discards stale packets before drop-tail buffers overflow, halting retry packet storms and clearing bufferbloat latency.
Autonomous AI Governor Continuous closed-loop background daemon. When channel health falls below 60% or collision rates exceed 18%, automatically triggers coordinated multi-layer stabilization and logs the action in history.
Note on Offline Usage: The application does not strictly require an external internet connection or Gemini API key. If no key is configured in .env, the deterministic Bianchi Markov analytical engine processes all metrics locally and returns identical structured stabilization recommendations.
